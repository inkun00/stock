# 📈 KOSPI Morning Alpha (코스피 모닝 픽)

매일 아침 장 시작 전(08:15 KST)에 코스피(KOSPI) 시장의 전체 상장 주식을 정밀 분석하여, 당일 및 단기 상승 확률이 가장 높은 **상위 5개 종목**을 도출하고 직관적인 웹 대시보드로 제공하는 퀀트 추천 웹앱입니다.

---

## ✨ 핵심 기능

1. **KOSPI 전 종목 전수 퀀트 스코어링**
   - 시가총액, 거래대금, 외인/기관 수급, 5/20/60일선 정배열, 5·20 골든크로스, RSI, 볼린저 밴드, 거래량 폭발도를 종합한 100점 만점 복합 퀀트 알고리즘
   - 단순 종목 나열이 아닌 정규화된 **상승 확률(%)** 및 실전 매매 가이드 제공

2. **오늘의 TOP 5 인터랙티브 대시보드**
   - 1위(King Alpha 골드 배지)부터 5위까지 한눈에 비교
   - 종목별 기업 공식 로고, 핵심 시그널 태그칩(`#외인기관양매수`, `#골든크로스` 등)
   - 3줄 AI 분석 브리핑
   - 권장 진입가, 1차 목표가(+3.8~5.0%), 손절가(-2.0~2.5%), 손익비 가이드

3. **인터랙티브 캔들스틱 & 지표 차트 (모달)**
   - 5일선(주황), 20일선(시안), 60일선(보라) 이동평균선
   - 하단 거래량 바 차트
   - 마우스 호버 시 십자선(Crosshair) 및 시/고/저/종가 실시간 툴팁

4. **평일 아침 08:15 자동 배치 스케줄러 & 즉시 재분석**
   - 백그라운드 APScheduler가 평일 08:15에 최신 장외/장전 데이터를 취합하여 자동 분석 및 캐싱
   - UI 상단의 **[⚡ 즉시 재분석]** 버튼으로 언제든지 30초 내에 전 종목 최신 시세 기반 재분석 가능

5. **성과 검증 & 적중률 (Track Record)**
   - 과거 추천 종목의 당일 실제 최고가 및 종가 수익률 집계
   - 누적 승률(Win Rate %) 및 평균 최고 상승률 공개

## 🚀 빠른 시작 방법

### 1. 가상환경 및 패키지 설치
이미 프로젝트 폴더에 `.venv` 가상환경이 구축되어 있습니다.
```bash
# 가상환경 활성화 (PowerShell)
.\.venv\Scripts\Activate.ps1

# 의존성 설치 (필요시)
pip install -r requirements.txt
```

### 2. 원클릭 실행 (서버 + 브라우저 대시보드 자동 실행)
```bash
.\.venv\Scripts\python run.py
```
실행 후 기본 웹 브라우저에서 `http://127.0.0.1:8000`이 자동으로 열립니다.

│   ├── css/
│   │   └── style.css         # 다크 테마, 그라디언트, 반응형 스타일
